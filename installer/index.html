      Machine verified

      A live, read-only Wideband check observed the app, service, or macOS setting on this Mac.

      You confirmed

      You told the guide an account sign-in, two-factor setup, or real-world outcome is complete. Wideband does not pretend it can inspect private account details.

      Waiting

      The installer is still working, no proof exists yet, or the next action belongs to you.

      Needs attention

      A machine check failed or a completed task returned something that should be reviewed.

      If this page disconnects

      Progress is already saved. Reopen Wideband Setup from Applications or the installer disk image. Do not type localhost manually—the app supplies the private token and opens the correct port automatically.

      This page never guesses account status.

      Setup tools

      Check, repair, or get help.

      These tools use the same saved setup state. Diagnostics intentionally exclude credentials, profile answers, identity-file values, and raw logs.

      Private by design

      No password, token, two-factor code, custom profile answer, raw log, or .sop-vars value is placed in the support bundle.

      Recoverable deactivation

      Pause the Wideband runtime?

      This stops Wideband background jobs and moves the agent and job definitions into a private recovery folder. It does not delete client work, account sign-ins, configuration, or setup history.

      macOS settings remain yours.

      Remote Login, Screen Sharing, and privacy approvals are not silently changed. Review them in System Settings after deactivation if you no longer want them enabled.
